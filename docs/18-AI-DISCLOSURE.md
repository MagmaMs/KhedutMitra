# AI Usage Disclosure

In the spirit of transparency for CodeCraft '26, the following AI tools were utilized in the ideation and development of KhedutMitra:

## 1. Code Generation & Assistance
- **Claude / Gemini:** Used via specialized agents for scaffolding boilerplate code, generating the Magic Patterns design system components, and drafting comprehensive documentation (like this one).

## 2. Product Features (Integrated AI)
- **Generative AI (OpenAI/Anthropic):** APIs utilized for the "AI Advisory" module to generate contextual farming tips based on weather and soil data.
- **Machine Learning (Vision):** Pre-trained ResNet/PlantVillage models used for the "Disease Tracker" feature to classify leaf diseases from uploaded images.

## 3. Design & Copy
- LLMs were used to generate mock data (e.g., Hindi/Gujarati translations, dummy community posts, and sample crop listings) to populate the MVP for a realistic demo.

*All core architectural decisions, business logic, and integrations were directed and assembled by the hackathon team.*
