# Agri-Marketplace Logic (Inputs)

*(Note: Distinct from the Farmer-to-Consumer crop listings)*

## 1. Scope
A directory for farmers to find agricultural inputs: seeds, fertilizers, and machinery rentals.

## 2. Design
For the hackathon scope, this is a read-only directory populated by localized dummy data representing local vendors.

## 3. Features
- Categories: Seeds, Fertilizers, Machinery.
- Price comparison.
- Contact Vendor functionality.
